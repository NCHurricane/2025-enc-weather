# Example Storm Data - AL052025 - Erin (2025 Atlantic Season)

This directory contains real NHC text products from Erin (AL052025) for development and testing purposes.

## Purpose

-   **Documentation**: Shows the complete structure of cached storm data
-   **Testing**: Allows frontend development without active tropical systems
-   **Development**: Provides realistic, production data for testing storm pages
-   **Onboarding**: New developers can see exactly what cache scripts produce

## Data Files

### Text Products (JSON)

-   `TCPAT1.json` - Public Advisory (English)
-   `TCMAT1.json` - Forecast/Advisory with track coordinates
-   `TCDAT1.json` - Forecast Discussion
-   `PWSAT1.json` - Wind Speed Probabilities
-   `TCUAT1.json` - Tropical Cyclone Update (if issued between advisories)
-   `TASAT1.json` - Public Advisory (Spanish)
-   `TDSAT1.json` - Discussion (Spanish)

**Note**: Graphics (PNG files) are excluded from the repository due to size. The frontend will display NHC graphics via active/js/storm-graphics.js when viewing this example storm.

## Storm Numbering Convention

AL052025 is the 5th Atlantic storm of 2025:

-   Storm ID: `AL052025`
-   Advisory Number: **1** (calculated as: 5 % 5 + 1 = 1)
-   WMO Product Codes: `TCPAT1`, `TCMAT1`, `TCDAT1`, `PWSAT1`
-   Spanish Products: `TASAT1`, `TDSAT1`

**Note**: These text products are displayed via active/js/storm-text.js, using JSON files cached using caching PHP scripts.

## Usage

### Local Testing

```bash
# Serve the site
php -S localhost:8000

# Navigate to the example storm
http://localhost:8000/active/?storm=AL052025
```

### Frontend Development

The storm page will load this cached data automatically when `storm=AL052025` is in the URL. Graphics will be fetched from NHC servers.

### Backend Testing

Test the advisory writer with this storm:

```bash
php active/api/advisory_writer_atlantic.php --storm=AL052025
```

## Data Source

These are **real NHC text products** cached from Tropical Cyclone Erin from 2025 Atlantic tropical system. The JSON structure matches exactly what the production cache scripts generate.

## Graphics Note

PNG graphics are **not included** in the repository to save space. When viewing this storm, the frontend will:

-   Display graphics via NHC hotlinks (if storm still active)
-   Show "Graphics unavailable" message (if storm archived)

For local development with graphics, run the advisory writer cache script against this storm ID.

## Data Structure

Each JSON file contains:

```json
{
    "content": "Full text of the NHC product",
    "timestamp": "2025-10-13T18:00:00Z",
    "product_type": "TCP|TCM|TCD|PWS|TCU|TAS|TDS",
    "storm_id": "AL052025"
}
```

## Note

This is **real archived data** from 2025. Live storm data during active tropical weather is generated by cache scripts in `active/api/` and excluded from version control via `.gitignore`.
