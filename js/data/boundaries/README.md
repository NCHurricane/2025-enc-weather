# World border reference data

`world-countries-50m.geojson` is derived from Natural Earth
`ne_50m_admin_0_countries`, version 5.1.1:

https://www.naturalearthdata.com/downloads/50m-cultural-vectors/

The source polygons were converted to GeoJSON at five-decimal coordinate
precision. Source attributes were removed because the site uses this file only
as a noninteractive border reference overlay. Natural Earth data is public
domain.
